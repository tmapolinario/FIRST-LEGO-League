# FIRST LEGO League Portugal

Site estático — versão final. Inclui seis páginas, imagens e vídeo.

## Publicar no GitHub Pages

1. Extraia este ZIP.
2. Carregue todos os ficheiros para o repositório, incluindo a pasta assets. O index.html deve ficar na raiz, sem uma pasta adicional.
3. Nas definições do repositório, em Pages, escolha Deploy from a branch, a branch main e a pasta / (root).
4. Aguarde a publicação e abra o endereço indicado pelo GitHub.

Não necessita de instalação nem compilação. As ligações internas são relativas e funcionam também num endereço de projeto do GitHub Pages.

O domínio www.fjuventude.firstlegoleague.pt não é configurado automaticamente.

A política de privacidade foi adaptada ao projeto; os detalhes operacionais de conservação e de eventual partilha de dados ainda precisam de confirmação pela Fundação.
